# Security Policy

## Supported version

Security fixes are applied to the latest published release of
PsicoseadoSSTool.

## Reporting a vulnerability

Do not publish an unpatched vulnerability, credential, private log or personal
information in a public issue. Contact Psicoseado privately through the Discord
community linked in the project README and include:

- the affected version;
- steps needed to reproduce the issue;
- the expected and actual behavior;
- the possible impact.

## External tools and scripts

PsicoseadoSSTool launches third-party executables and PowerShell scripts. Those
projects are maintained by their respective authors and are not covered by the
MIT license of this repository. Review their source, download location and
license before executing them. Remote scripts can change independently of this
repository.

Only use this software on systems you own or have explicit permission to
inspect. Administrator access increases the impact of every downloaded tool.
